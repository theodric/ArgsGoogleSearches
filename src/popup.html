Google Search Arguments
Add any arguments (one at a time!) that you would like to append to *all* your Google.com searches. For example:
        
  • -site:pinterest.* will remove all results from Pinterest
    •     
  • -ai will remove Google AI suggestions, but allow knowledge boxes
    •     
  • reddit will add the word reddit to the end of every search query
    •     
  • "potato" (including the quotes) will require every query to return results which reference potatoes

The &udm=14 parameter (appended to URL) will further minimize AI "helpfulness."
